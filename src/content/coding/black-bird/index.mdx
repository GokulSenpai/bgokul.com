## Overview

Black Bird was my first project: a 1:1 clone of Flappy Bird, redone in black and white. The goal was to learn how a complete game fits together, from input and physics to menus, scoring and sound.

## How it works

The bird is a Rigidbody2D. Each tap zeroes its velocity and adds an upward force, and it tilts up on the tap before easing back into a dive as it falls.

The obstacles and background scroll as parallax layers built on object pooling. A fixed set of objects is spawned once at startup, moved across the screen, and recycled as soon as it leaves, instead of being destroyed and created again.

Spawn positions scale with the screen's aspect ratio, so the spacing holds up on different phones.

The systems talk to each other through the observer pattern. Scoring, dying, the countdown finishing and the game starting are all C# events, and the game manager, the player and the parallax layers each subscribe to the ones they need instead of holding references to each other.

A coroutine runs the 3-2-1 countdown, a Shader Graph dissolve effect fades sprites in, and the high score is saved between sessions.
