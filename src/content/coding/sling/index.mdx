## Overview

Sling is a prototype inspired by Angry Birds and Paper Toss, moved into third person. Pull back to sling the ball, and it sticks wherever it lands.

## Destructible objects

I also used it to experiment with destruction. A cube splits dynamically into smaller cubes, and the fragments then disappear. They're returned to an object pool instead of being destroyed, so breaking things repeatedly doesn't keep allocating new objects.
