## Overview

CCC is a first-person character controller written from scratch for a horror game. I've always found the traditional controllers "floaty", so I decided to make it realistic.

## How it works

Each behaviour (walking, zooming, peeking around a corner, picking something up to inspect it) is its own state in a state machine. That keeps every mode of movement in one small, readable class, and adding or removing a behaviour doesn't mean untangling the others.

Head bob and sway are driven by sine waves, so the camera rhythm follows the player's speed instead of playing a fixed animation.

All of this can be customised to fit what a project needs.
